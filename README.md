## 📖 About The Project

Meal Metric is an intelligent web-based nutrition and fitness management platform designed to help users maintain a healthy lifestyle through personalized dietary recommendations and calorie tracking.

The system enables users to monitor daily food intake, calculate BMI, analyze nutritional values, and receive customized meal plans based on their fitness goals. By combining nutrition science with modern web technologies, Meal Metric provides a simple and effective solution for healthy living.
